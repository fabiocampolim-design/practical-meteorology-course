## A. Rights and licence — decide before the first push

**A1. Licence by origin has a third case here.** The notes, slides, figure
crops, exercise texts and the guide are derived from a CC BY-NC-SA 4.0 book;
ShareAlike binds that content to **CC BY-NC-SA 4.0** — it cannot be
Apache-2.0. The from-scratch *code* (`ferramentas/*.py`, `comum/*.py`,
`comum/*.sty`, notebook code cells) is ours and takes **Apache-2.0** per
rule 17. Recommended layout (REUSE convention, and the only one the checker
accepts): `LICENSE` = Apache-2.0 verbatim (code) + `NOTICE`;
`LICENSES/CC-BY-NC-SA-4.0.txt` (content); the README's `## Licença` section
says which paths carry which, followed by the mandatory `### Disclaimer` and
the non-affiliation note (Stull / UBC, Unidata MetPy, climlab, Py-ART, Satpy
and the other named packages). `conformance.py`'s `license-clauses` rejects a
non-Apache/GPL `LICENSE`, so the CC text must sit *beside* `LICENSE`, not in it.
The current README already states the CC inheritance correctly (in
Portuguese) but has no disclaimer, no non-affiliation note and no code licence.

**A2. Third-party figures inside the book are not covered by the book's
